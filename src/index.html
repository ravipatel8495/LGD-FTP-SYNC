FAQ

How does this app work?

Each row is one product type plus a file or folder to watch. Existing files upload when watching starts. After that, a changed file waits 30 seconds, then uploads. The Activity Log shows upload %. LGD files go to /LGD and NATURAL files to /NATURAL.

Which connection type and port should I use?

FTP port 21 (plain), FTPS explicit port 21, FTPS implicit port 990, SFTP port 22. The port fills in when you pick a type.

How do LGD and NATURAL share one FTP account?

Same host, user, and password. Add a second row with + Add another type. LGD uploads to /LGD, NATURAL to /NATURAL.

Can I watch a single file instead of a folder?

Yes. Click File… for a CSV/Excel file, or Folder… for a whole folder.

Does it keep working if I close this window?

Yes. Close hides to the tray (menu bar on Mac). Use tray Quit to exit fully.

What happens after a shutdown or restart?

After you click Start Watching once, the app starts at login and resumes watching by itself.

Are deleted files also deleted on the server?

No. Only new and changed files are uploaded. Hidden files (starting with a dot) are skipped.

Where are my settings stored?

In config.json on this computer. Host, user, and password reload after an update. Keep this PC trusted — the password is stored in plain text.

Upload failed — what do I check?

Click Test FTP. Check host, user, password, port, and firewall. Try another connection type. Failed uploads retry when the file changes again.
